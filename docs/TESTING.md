## 已隔离出的依赖组合退出异常

测试 Metamod 2.0.0-dev+1469 + CS2KZ 0.0.173 + MultiAddonManager v1.6-0-ge85a483，在地图运行约半分钟后退出，出现 Windows `0xC0000005`。有 ShowPos 的调用栈位于 MultiAddonManager 静态析构及 Metamod hook 移除；**完全不加载 ShowPos 和测试探针的同等时长基线也重现相同退出码**。较短基线可正常退出。

因此不能将该依赖组合的整服退出标为通过，也不能以一次短测试退出 0 证明问题不存在。本次遵守“核心完全不改”，未修改 Metamod、CS2KZ 或 MAM 来掩盖该问题。此问题属于尚需独立诊断的已有依赖组合生命周期故障，仍可能影响实际停服；保留对照日志供继续定位。

前期 ShowPos 自身的两个问题已修复：控制台回调内同步移除自身导致卸载等待；静态 ConCommand 在 ICvar 销毁后析构导致退出异常。当前 DLL 使用分离的清理策略和显式命令生命周期。
